## WORKFLOW: FRAGMENT CREATION
1. Write fragment text in markdown
2. Render to PDF via Typst or Scribus
3. Generate sigil SVG in Inkscape
4. Embed subliminal via Python/pycairo
5. Print on cotton paper, hand-assemble
6. Ship with cipher envelope

## WORKFLOW: RELIC PRODUCTION
1. Model sacred geometry in Blender with Sverchok nodes
2. Apply gold/red materials, render passes
3. Export STL for 3D printing
4. Post-process, number, sign
5. Package in black linen box with gold foil sigil
6. Photograph for catalog

## WORKFLOW: AUDIO
1. Compose 40Hz drone in Python/wave or Audacity
2. Add breathing envelope, binaural layers
3. Export WAV/FLAC
4. Embed as WebAudio in website
5. Include as download in fragment package
